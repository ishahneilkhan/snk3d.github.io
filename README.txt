Shah Neil Khan - 3D Design Review (সাইট + অ্যাডমিন)

ফাইল:
  index.html  = ক্লায়েন্ট যা দেখে (সাইট)
  data.js     = সব প্রজেক্টের তথ্য
  common.js, style.css = সাইটের কোড ও ডিজাইন
  admin.html  = শুধু আপনার জন্য, হোস্টিংয়ে আপলোড করবেন না

নতুন প্রজেক্ট যোগ করার নিয়ম:
 1. আপনার কম্পিউটারে admin.html ডাবল ক্লিক করে খুলুন (ইন্টারনেট লাগবে)।
 2. "+ নতুন প্রজেক্ট" চেপে নাম, ছবি ও ৩ডি কোড দিন, সেভ করুন।
 3. "data.js ডাউনলোড" চাপুন।
 4. ডাউনলোড হওয়া data.js দিয়ে হোস্টিংয়ে থাকা পুরনো data.js বদলে দিন।

সাইট চালু করা (ফ্রি): netlify.com/drop এ index.html, data.js, common.js, style.css চারটা ফাইল একসাথে ফেলুন।
